        script.js · addProcess()

        Process management

        Every task is a process record with a PID, priority, burst time and a state that moves through READY, RUNNING, BLOCKED and COMPLETED. The process table is a simple Process Control Block list.

        script.js · cores[]

        Thread simulation

        Four logical cores run in parallel. Each tick, every busy core advances its process by one time unit, and idle cores pull new work from the ready queue.

        script.js · pickNext()

        CPU scheduling

        Three policies can be switched live: Priority, Round Robin with a quantum, and FCFS. Compare how the Gantt chart and waiting times change.

        script.js · aging

        Priority and aging

        Low-priority tasks gain priority the longer they wait, so they do not starve behind a steady stream of urgent work.

        worker.js

        Parallel processing

        Sensor analysis runs inside a Web Worker, a separate thread. The page stays responsive while the worker checks limits, trends and health score.

        script.js · S.lock

        Synchronization

        Control processes need the actuator mutex. If another process holds it, they become BLOCKED until it is released, which prevents conflicting commands.

        sensors + canvas

        Real-time monitoring

        Sensors are sampled every 2.5 seconds with threshold lines drawn on each graph. Crossing a limit raises an event in the log.
